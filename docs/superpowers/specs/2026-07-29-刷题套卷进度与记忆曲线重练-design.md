# 刷真题：套卷进度 + 记忆曲线重练（A+C）设计

日期：2026-07-29
范围：刷真题模块（drill）的两项优化 ——
- **A · 套卷进度与列表**：按来源（套卷）组织题库，记录每题练习进度，支持四种练习模式。
- **C · 记忆曲线重练**：根据每题对错历史与时间，自动推算"该重练的题"，跨套卷汇总成今日待重练队列。

明确**不在本轮**：按考点/薄弱点维度练题（思路 B，需题目标注考点，另立项目评估成本）；单词练习可选范围与词表分组（属另一模块）。

---

## 1. 背景与问题

现状 `renderDrillHome` / `startDrill`（`static/app.js`）：
- 每次练习 `shuffle` 全部或按 part 过滤的题目，乱序混合。
- 不记录"哪套卷做过、做到哪、正确率多少"，无法反复有针对性地练。
- 错题本（`S.wrong`）只覆盖"做错的题"，做对的题过后不再出现，无法防遗忘。

目标：让用户能**按套卷反复练**、**看到每套进度**、**该重练的旧题自动浮现**。

## 2. 数据结构

用户 state 新增（服务器对结构透明，无需改 server）：

```js
S.drillProg = {
  [qid]: {
    n: 3,              // 累计练习次数
    ok: 2,             // 累计做对次数
    lastOk: 1,         // 最近一次是否答对 0/1
    lastAt: 1722000000000, // 最近练习时间戳 ms
    due: '2026-08-03', // 下次该重练的日期（记忆曲线）
    stage: 2           // 连对阶段（记忆曲线索引用）
  }
}
```

正确率、完成度、待重练数均由 `drillProg` 聚合算出，不另存。

### 记忆曲线规则
复用现有常量 `REVIEW_IV = [1, 3, 7, 15]`：
- 答对：`stage++`；若 `stage >= REVIEW_IV.length` → 标记已巩固（`due = ''`，不再推送）；否则 `due = today + REVIEW_IV[stage]`。
- 答错：`stage = 0`，`due = today + 1`；同时写入错题本 `S.wrong`（沿用现有 `recordWrong` 逻辑，两者并存不冲突）。

### 向后兼容
老用户无 `S.drillProg`，`ensurePlan()` 中补 `S.drillProg = S.drillProg || {}`；首次进入进度显示 0，做一题积累一题。`S.wrong` 错题本逻辑保持不变。

## 3. 刷真题首页：套卷列表

按 `src`（题库中的来源字段，13 个，如"考试试题（一）""湖南模拟一"）分组渲染套卷卡片。每张卡显示：
- 套卷名 + 题数（如 `考试试题（一）· 30 题`）
- 进度：`已做 X / Y` + 进度条
- 正确率：`Z%`（ok/n）
- 待重练：`N`（该套卷中 `due ≤ 今天` 的题数，N>0 时高亮）

点开套卷 → 练习模式选择：
1. **顺序做**（按原题号顺序，便于对照原卷）
2. **只做没做过的**（`drillProg` 中无记录的题）
3. **只做做错的**（`drillProg` 中有记录且 `ok < n` 的题）
4. **重做整套**（不删历史，仅从头再过一遍）

首页顶部保留：
- **今日待重练**卡片：跨所有套卷 `due ≤ 今天` 的题数，一键进入重练（见 §4）。
- 现有"全部混合练习""按题型（part）练习"入口。

## 4. C：记忆曲线重练

- 重练队列 = 所有套卷中 `due ≤ 今天` 且未巩固的题，进入后按 `due` 升序（最旧的先练）。
- 重练复用现有 `showDrillQ` / `answerDrill` 答题界面，仅数据源不同。
- 今日页（home）的"刷真题"任务行，进度文案补充 `待重练 N`，与错题本（`wrongDue`）并行显示。

## 5. 单题练习按钮

- 套卷展开为题目列表时，每题末尾一个"练"按钮 → 单题练习模式：只练该题，答完显示对错+解析后返回列表。
- 错题本（`renderWrong`）每题在现有"看题"旁补一个"重练此题"按钮，进入同一单题模式。

## 6. 涉及文件

## 7. 错误与边界处理

- `drillProg` 记录引用已不在 `QUESTIONS` 中的 qid（题库更新后）→ 聚合统计与重练队列跳过查不到题的条目。
- 某套卷在某模式下无题（如"只做没做过的"但全做过）→ 提示并返回模式选择。
- `due` 为空（已巩固）或未来日期 → 不进今日待重练。
- 记忆曲线与错题本日期基准统一用 `todayStr()`，避免时区/跨天不一致。

## 8. 测试要点

- 新用户：进度从 0 开始，做一题后进度/正确率更新。
- 答错一题：进错题本 + `stage=0` + `due=明天`；次日出现在今日待重练。
- 连对 `REVIEW_IV.length` 次：标记巩固，不再推送。
- 四种模式抽题范围正确（顺序/未做/做错/整套）。
- 单题模式答完正确返回列表。
- 老用户 state（无 `drillProg`）正常加载不报错。
- 今日页"刷真题"行显示待重练数。
